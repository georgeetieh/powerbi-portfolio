## Project 2: FIELDVISION | Production Intelligence Command Center

### Dashboard Preview

![FIELDVISION Production Intelligence Dashboard](Field%20division%20well%20intelligence.png)

### Project Overview

FIELDVISION is an oil and gas production analytics dashboard designed to support well-level monitoring, production performance analysis, and operational decision-making across Nigerian onshore and offshore fields.

The dashboard brings production trends, well health indicators, pressure, water cut, downtime, and short-term production changes into a unified monitoring interface.

### Key Features

- Production Monitoring: Compare actual oil production against production targets.
- Well Health Index: Combine production achievement, availability, pressure, water cut, and downtime into a composite indicator.
- Decline Detection: Compare recent and previous 30-day average oil production to identify potential changes.
- Operational Diagnostics: Monitor production, pressure, and water cut status.
- Onshore and Offshore Analysis: Explore a dataset covering selected Nigerian oil fields.
- Interactive Filtering: Analyse results by well, field, and location type.

### Tools Used

- Power BI
- DAX
- Power Query
- Excel

### Data Methodology

This project uses synthetic well-level production and operational data, with publicly available field-level information used as calibration context where available. Individual well measurements and diagnostic results are illustrative and should not be interpreted as actual operating data from the named fields.
